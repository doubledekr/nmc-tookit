Presence & IT admin

Who has the toolkit open right now

Toolkits heartbeat once a minute while open (name + timestamp only, nothing else). Green = seen in the last 3 minutes.

Mirrored banker save files

Each banker's toolkit mirrors its full save to the hub whenever it can reach it — separate from their local file, which always works offline. These carry client data, so the admin token is required and the list shows metadata only until you open one.

Pricing API (optional plug-in)

Wire a pricing-engine or aggregator endpoint that returns {"rates":{"Conventional":6.125,...}}. Once saved, the Rate desk shows leadership a one-click "Pull" — they review, then Publish. Leave blank to keep rates fully manual.
